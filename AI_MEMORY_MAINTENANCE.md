# AI MEMORY MAINTENANCE

Run periodically or after major milestones.

## Compress
Turn long notes into short factual bullets.

## Deduplicate
If the same fact exists in multiple AI memory files, keep it in the most appropriate file.

## Delete
Remove:
- resolved bugs
- obsolete decisions
- temporary assumptions
- duplicated source descriptions
- stale TODOs

## Promote
Move important temporary information:
SESSION_MEMORY → AI_BRAIN / DECISIONS / KNOWN_ISSUES

## Archive
Old AI_CHANGELOG entries may be archived when they no longer help future work.

## Golden Rule
Memory should explain the project, not become another project that the AI has to read.
